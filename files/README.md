# Finance House Dubai – Gold Loan API

FastAPI backend for the Gold Loan Valuation & Eligibility Dashboard.

## Project Structure

```
backend/
├── main.py                     # FastAPI app + all routes
├── models.py                   # Pydantic request/response models
├── seed_data.py                # Generate dummy Emirates ID data (run once)
├── requirements.txt
├── data/
│   ├── dummy_customers.json    # generated by seed_data.py
│   └── dummy_loans.json        # generated by seed_data.py
└── services/
    ├── gold_service.py         # Live gold price + historical + prediction
    ├── customer_service.py     # Load customer/loan data by Emirates ID
    ├── loan_calculator.py      # LTV calculation with all adjustment factors
    └── risk_analyzer.py        # User & company risk scoring
```

---

## Setup

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate dummy Emirates ID / customer data (run once)
python seed_data.py

# 3. Start the server
uvicorn main:app --reload --port 8000
```

Swagger UI → http://localhost:8000/docs

## API Endpoints

### `GET /health`
System health check.

---

### `GET /gold/price`
Fetches the live XAU price from `gold-api.com` and converts to **AED per gram**.

```json
{
  "price_aed_per_gram": 285.4,
  "price_usd_per_oz": 2415.5,
  "updated_at": "2024-01-15 10:30 UTC"
}
```

---

### `GET /gold/insights?tenure_months=24`
Returns 6-month historical gold prices + polynomial-regression forecast for the
requested tenure.

---

### `GET /customer/{emirates_id}`
Returns customer profile (name, nationality, CIBIL score, risk category, etc.).

**Sample IDs** (from seed script):
| Emirates ID | Customer | CIBIL | Risk |
|---|---|---|---|
| `784-1985-1234567-1` | Ahmed Al-Mansoori | 780 | A+ |
| `784-1990-2345678-2` | (random) | varies | varies |
| `784-1978-3456789-3` | (random) | varies | varies |

---

### `GET /customer/{emirates_id}/loans`
Returns full loan history (active, closed, missed EMIs, outstanding balance).

---

### `POST /loan/calculate`  ← **Main endpoint**

Request body:
```json
{
  "emirates_id": "784-1985-1234567-1",
  "carat": "22K",
  "gold_weight_grams": 1577.19,
  "tenure_months": 24,
  "job_profession": "Government Employee"
}
```

The response contains **everything** the dashboard needs:

| Field | Description |
|---|---|
| `system_decision` | Pre-Approved / Manual Review / Rejected |
| `recommended_ltv_pct` | Final LTV % after all adjustments |
| `gold_valuation_aed` | Weight × purity × live price |
| `eligible_loan_amount_aed` | Valuation × LTV |
| `cibil_score` / `cibil_label` | Score + Excellent/Good/Fair… |
| `remarks` | Auto-generated underwriter remark |
| `ltv_breakdown` | Individual adjustment factors |
| `customer_profile` | Name, ID, nationality, risk category |
| `loan_history` | Active/closed loans, missed EMIs, outstanding |
| `gold_insights` | Live price, 6-mo history, tenure forecast, trend |
| `risk_insights` | User risk score + company risk score (0–100) |

## LTV Calculation Logic

```
LTV = BASE_LTV (75%)
    × carat_multiplier        (24K=1.00 … 14K=0.84)
    × cibil_factor            (≥760=1.00 … <580=0.65)
    × missed_emi_penalty      (0 missed=1.00 … >5=0.78)
    × active_loan_factor      (max(0.80, 1 - active_loans × 0.06))
    × profession_factor       (Govt=1.00 … Freelancer=0.83)
    × gold_trend_factor       (rising ≥5%=1.05 … falling ≤-5%=0.90)
```

## Risk Score Logic

**User Risk (0–100, lower = safer)**
- CIBIL score (40 pts)
- Missed EMIs (20 pts)
- Active loan count (15 pts)
- Job profession stability (15 pts)
- Outstanding balance ratio (10 pts)

**Company Risk (0–100, lower = safer)**
- User risk contribution × 0.40 (40 pts)
- Collateral / LTV exposure (35 pts)
- Gold market trend (25 pts)

> **Key insight:** A risky borrower with rising gold = LOW company risk,
> because the lender can liquidate collateral at a premium.

## Gold Price Source

`GET https://api.gold-api.com/price/XAU`

- Returns USD per troy oz
- Converted to AED using fixed peg: **1 USD = 3.6725 AED**
- 1 troy oz = 31.1035 grams
- Falls back to a cached price if the API is unreachable

## Frontend Integration

Connect your React frontend to this API:

```javascript
// On form submit
const response = await fetch("http://localhost:8000/loan/calculate", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    emirates_id: "784-1985-1234567-1",
    carat: "22K",
    gold_weight_grams: 1577.19,
    tenure_months: 24,
    job_profession: "Government Employee"
  })
});
const data = await response.json();
// data.recommended_ltv_pct → "72%" hero card
// data.gold_insights.live_price_aed_per_gram → "AED 285.40/g"
// data.risk_insights.user_risk_label → "LOW RISK"
// etc.
```
