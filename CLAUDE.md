## Project Overview

Gold Loan Valuation & Eligibility Dashboard for Finance House Dubai. Two parts: a React/Vite frontend and a FastAPI backend. The backend lives in `backend/`.

## Commands

### Frontend
```bash
npm run dev          # Vite dev server (default port 5173)
npm run build        # Production build
npm run lint         # ESLint
npm run preview      # Preview production build
```

### Backend
```bash
cd backend
source .venv/bin/activate                    # .venv already exists in backend/
pip install -r requirements.txt
python seed_data.py                          # Run once to generate dummy_customers.json + dummy_loans.json
uvicorn main:app --reload --port 8001        # Must use port 8001 — frontend hardcodes BACKEND_BASE_URL = 'http://127.0.0.1:8001'
```

Swagger UI: http://localhost:8001/docs

> **Port note:** `vite.config.js` has a proxy config pointing to port 8000 — this is dead code. `App.jsx` makes all requests directly to `http://127.0.0.1:8001` (bypassing the Vite proxy entirely). `main.py`'s `__name__ == "__main__"` block also defaults to 8000 — always start via `uvicorn ... --port 8001`.

## Architecture

### Frontend (`src/App.jsx`)
Single-file React app with two screens toggled via `activeScreen` state:
- **CalculatorScreen** — form to collect carat, Emirates ID, gold weight, tenure, profession; fetches live gold rates on mount from `/api/gold-rate/live`
- **SummaryScreen** — displays full eligibility dashboard after `POST /loan/calculate`

No router, no state management library, no component files beyond `App.jsx`. Inline SVG gauges (`RiskGauge`, `CibilGauge`) and a hand-rolled SVG polyline chart (`PredictedLtvGoldTrendChart`) with hardcoded dummy data. Styled with Tailwind CSS v4 via `@tailwindcss/vite` plugin.

### Backend (`backend/`)

```
backend/
├── main.py                  # FastAPI app + all routes
├── models.py                # Pydantic enums + request/response models
├── seed_data.py             # One-time script to generate data/dummy_customers.json + data/dummy_loans.json
├── data/
│   ├── dummy_customers.json
│   ├── dummy_loans.json
│   └── gold_history.json    # 20-year real historical gold data (required by gold_service)
└── services/
    ├── gold_service.py      # Live gold price (XAU→USD→AED/SAR) + ML prediction pipeline
    ├── customer_service.py  # Load customer/loan records by Emirates ID from JSON files
    ├── loan_calculator.py   # LTV calculation with all adjustment multipliers
    ├── risk_analyzer.py     # User risk score (0–100) + company risk score (0–100)
    └── uaepass_service.py   # UAE PASS identity stub (real integration commented out)
```

### Main API Flow (`POST /loan/calculate`)

1. Load customer profile + loan history from `data/dummy_customers.json` / `data/dummy_loans.json`
2. Optionally enrich with UAE PASS identity (currently stub only — returns hardcoded profiles for 3 known Emirates IDs)
3. Fetch live XAU/USD from `https://api.gold-api.com/price/XAU`, convert to SAR (peg: 1 USD = 3.7500 SAR) and AED (peg: 1 USD = 3.6725 AED)
4. Build gold insights: load `data/gold_history.json`, fit polynomial (degree-3 Ridge, all 20 years) + linear (last 90 days) models, blend 35%/65%, predict per tenure
5. Calculate LTV via multiplier chain (see below)
6. Score user + company risk (0–100 each)
7. Return `LoanCalculationResponse` — single payload for the entire dashboard

### LTV Calculation (`services/loan_calculator.py`)

```
LTV = 75% base
    × carat_multiplier        (24K=1.00 … 14K=0.84)
    × cibil_factor            (≥760=1.00 … <580=0.65)
    × missed_emi_penalty      (0=1.00 … >5=0.78)
    × active_loan_factor      max(0.80, 1 - active_loans × 0.06)
    × profession_factor       (Govt=1.00 … Freelancer=0.83)
    × gold_trend_factor       (RISING ≥5%=1.05 … FALLING ≤-5%=0.90)
```

`system_decision` thresholds: ≥70% → Pre-Approved, 55–70% → Manual Review, <55% → Rejected.

### Currency Note

All monetary values are in **SAR** (Saudi Riyal). Gold price converted via `SAR_PER_USD = 3.7500` peg.

## Key Data Files

- `backend/data/gold_history.json` — required at startup; `gold_service.py` raises `FileNotFoundError` if missing. Format: `[{"day": "YYYY-MM-DD", "max_price": float}, ...]` (prices in AED per troy oz).
- `backend/data/dummy_customers.json` + `backend/data/dummy_loans.json` — generated by `seed_data.py`. Three seeded Emirates IDs: `784-1985-1234567-1`, `784-1990-2345678-2`, `784-1978-3456789-3`.

## UAE PASS Integration

Currently stubbed in `backend/services/uaepass_service.py`. To enable real integration: set `UAEPASS_CLIENT_ID` and `UAEPASS_CLIENT_SECRET` in `backend/.env` and uncomment the production path in `fetch_uaepass_profile()`.
